# KiCad Setup

## 1. Configure Paths

Go to `Preferences -> Configure Paths` and add `TECHNULGY_KICAD` pointing to this folder

## 2. Configure Symbol Libraries

!!! You only see those in either the Schematic Window or the project windows !!!

Go to `Preferences -> Manage Symbol Libraries...` and add an entry, called `Technulgy Libs` pointing to `${TECHNULGY_KICAD}/KiCad - Libraries/sym-lib-table`.

## 3. Configure Footprint Libraries

!!! You only see those in either the PCB Window or the project windows !!!

Go to `Preferences -> Manage Footprints Libraries...` and add an entry, called `Technulgy Libs` pointing to `${TECHNULGY_KICAD}/KiCad - Libraries/fp-lib-table`.

## 4. Configure Desing Blocks Libraries

Go to `Preferences -> Manage Design Block Libraries...` and add an entry, called `Technulgy Libs` pointing to `${TECHNULGY_KICAD}/KiCad - Design Blocks/design-block-lib-table`.
